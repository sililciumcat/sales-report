# Sales Analytics CLI Tool

Модульная консольная утилита на Python для автоматизированной агрегации, очистки и анализа данных о продажах.

## Основные возможности

* **Пакетная обработка:** Автоматическое сканирование и загрузка всех CSV-файлов из указанной директории.
* **Валидация и очистка:** Проверка наличия обязательных колонок и автоматическое удаление дубликатов.
* **Расчёт аналитики:** Агрегация общей выручки, разбивка продаж по категориям и определение лидеров продаж.
* **Экспорт отчётов:** Выгрузка результатов в форматах CSV и итогового текстового файла (summary.txt).
* **CLI-интерфейс:** Гибкая настройка путей ввода и вывода через аргументы командной строки.

## Структура проекта

```
sales-report/
├── data/               # Директория с исходными данными (CSV)
├── reports/            # Директория сгенерированных отчётов
├── src/
│   ├── processor.py    # Загрузка, валидация и очистка данных
│   ├── metrics.py      # Бизнес-логика и расчёт аналитики
│   └── reporter.py     # Экспорт результатов (CSV / TXT)
├── main.py             # Точка входа и парсинг CLI-аргументов
└── requirements.txt    # Список зависимостей проекта
```
## Установка и запуск

1. Клонирование репозитория:
   ### git clone https://github.com/sililciumcat/sales-report
   ### cd sales-report

2. Создание виртуального окружения и установка зависимостей:
   ### python -m venv venv
   ### source venv/bin/activate  # Для Linux/macOS
   ### venv\Scripts\activate   # Для Windows

   ### pip install -r requirements.txt

## Примеры использования

Стандартный запуск с настройками по умолчанию:
### python main.py

Запуск с указанием кастомных директорий:
### python main.py --data_dir custom_data/ --output_dir custom_reports/

Справка по доступным флагам:
### python main.py --help
